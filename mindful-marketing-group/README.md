# Mindful Marketing Group website

A one-page site: `index.html` (everything is in this one file) and `logo.svg`.

## Before going live

- Replace everything in `[brackets]` with real content: client names, results, quotes, logos and the "Trusted by" number.
- Near the bottom of `index.html`, fill in `CONFIG`:
  - `calendarUrl`: your Calendly or Cal.com booking link
  - `formEndpoint`: a Formspree link, so applications get emailed to you
  - `videoEmbedUrl`: a YouTube embed link for the intro video

## Putting it online with Netlify

Connect this repo in Netlify, choose the `mindful-marketing-site` branch, and set the base directory to `mindful-marketing-group`. There's no build command.
